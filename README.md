# Claude Certified Associate – Foundations (CCAO-F): 2-Hour Exam Prep

Course materials for the O'Reilly live training *Claude Certified Associate Exam Prep: A Two-Hour Crash Course*. The official [Exam Guide (v1.0)](https://everpath-course-content.s3-accelerate.amazonaws.com/instructor%2F6nizmqk8tpzpfjvt6qmmav7rh%2Fpublic%2F1783542847%2FClaude+Certified+Associate+%E2%80%93+Foundations+Exam+Guide.pdf) is the compass for everything here.

## What's inside

| Path | What it is |
|---|---|
| `presentation/claude-associate-exam-prep.html` | Live slide deck (remark.js). Open in a browser; press `P` for presenter notes. |
| `lessons/` | One markdown lesson per exam domain, each with demos and use cases to work through in claude.ai |
| `lessons/practice-questions.md` | Original exam-style practice questions, weighted by domain, with answers |
| `cheatsheet/ccao-f-cheatsheet.pdf` | Printable cheatsheet of the whole course (≤10 pages) |
| `assets/demo-files/` | Fictional files used in the demos (upload them to Claude) |
| `research/` | Sourced research notes behind the materials |

## Exam at a glance

60 items · 120 minutes · scaled score 720/1,000 to pass · $99 · Pearson VUE (online or test center) · valid 12 months, free on-time renewal · closed book · English only. Registration currently requires a Claude Partner Network company email.

## Before the session

1. A Claude account (Pro or higher recommended so you can create Projects).
2. Download this repo so you can upload the files in `assets/demo-files/`.
3. Optional: Anthropic's eight-course prep path on the [Partner Academy](https://anthropic-partners.skilljar.com/path/claude-certified-associate-foundations) and the free [AI Fluency](https://academy.claude.com/courses/ai-fluency-framework-foundations) course.

All demo files are fictional. Practice questions are original and are not drawn from the live exam.
