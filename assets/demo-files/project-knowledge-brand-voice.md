# Northwind Learning — Brand Voice & Content Rules (FICTIONAL)

> Upload this file as knowledge in a Claude Project during the Lesson 05 demo.

## Audience
Busy team leads at mid-size companies (50–500 employees). They read on mobile between meetings.

## Voice
- Plain, direct, warm. Second person ("you").
- Short sentences. No jargon without a one-line definition.
- Never use: "revolutionary", "game-changing", "unlock", "leverage" (as a verb).

## Formats
| Asset | Length | Structure |
|---|---|---|
| Newsletter blurb | 60–90 words | Hook → one takeaway → link |
| LinkedIn post | 120–180 words | Problem → example → takeaway → question |
| Course description | 100–150 words | Who it's for → what you'll do → outcome |

## Facts we can state
- Courses are 4 weeks, 2 hours per week, live online.
- Founded 2019. 12,000+ learners.
- Refunds within 14 days, no questions asked.

## Facts we must NOT state
- Any pricing (changes quarterly — link to the pricing page instead).
- Any partner or client names.
- Job-placement or salary-outcome claims.
